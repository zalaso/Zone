# Personal model pilot on a server

This path is retained for links from earlier engineering notes. The former maintainer-specific beta is not a public service of the repository, and its private operational records are not part of the distribution.

For version 1.0 use [self-hosting](self-hosting.md), [account and owner setup](getting-started.md), [personal AI connections](ai-connections.md) and [data handling](privacy.md). The generic files in `deploy/` are optional templates; no deploy, credential transfer or provider inference happens automatically.

Older `serve --auth-mode accounts` installations remain supported. Read [identity](identity.md) and take a verified backup before upgrading. Real-provider pilots require the operator’s explicit consent and budget; offline tests do not establish model quality or a hosted SLA.
